## 真实旧数据迁移

从用户授权的服务器目录只读取得同数据集的 state/usage；原始数据不进入仓库。样本为 v4，233 个 Key、13 个模型、168 份用量记录，其中 232 个 Key 配置 7 天限额。

`cmd/cpa-key-policy-check` 在私有临时副本上验证：

- 233 个 Key 的身份、哈希、限额、权限与模型引用保持一致。
- 13 个模型的基础价格、目标、策略及凭证规则保持一致，缺省倍率为 1。
- 保留原 35 天保留期内的 1,202 个 Key/日期用量记录及模型明细。
- 日、7 天、30 天的期初占用等于原滚动窗口已用额，升级不赠送额度。
- 重复配置、落盘和重载保持周期状态一致，不重复结转。

样本 SHA-256：

```text
state eb92727d00d4ed14a4755ae9186eab9c77aea360c1cb4cf299a6e17014e4bde9
usage 4c1515cc145ad4d51bdbe50cecb1631bb7da973448be33a6aef473bd64cf0be8
```

固定演练时间：`2026-09-12T14:35:00+08:00`。样本未配置 30 天限额，该分支通过固定时间的本地周期场景验证。

## 失败恢复与计费

- 无法保存迁移备份时拒绝迁移，原始文件字节保持一致。
- usage 已写成 v5、state 写入失败后，再次启动保留既有周期与期初消费并完成迁移；原备份保持原始字节。
- 手动重置只恢复选中周期，原历史与其他周期保持；停机跨多个周期后仍沿用原到期节奏。
- 计费倍率不改变实际 Token，基础价格导入保留倍率。
- 认证拒绝仅输出宿主支持的 `Authenticated: false`，保留实际额度限制。

## 浏览器与共享库

浏览器通过 ego-browser 操作本地真实管理 API，使用合成用户数据：

- 桌面列表、状态区分、搜索、详情及返回后保留搜索条件。
- 张三 7 天额度从剩余 $46.70 恢复到 $50.00，30 天仍为 $196.70；历史消费保留。
- 倍率从 1.1 保存为 1.25，列表回读最终输入价 $2.50、输出价 $12.50。
- 390px 移动列表和重置弹窗；320px 页面及弹窗无横向溢出。
- 部分模型日额度耗尽时，弹窗默认选择日额度并解释模型日额度同时恢复。
- 深色主题可读。

本机 macOS 使用 `-tags cshared -buildmode=c-shared` 编译后，通过导出的 ABI 函数真实调用插件：迁移 233 个 Key 的副本，创建本地探针模型与 Key，完成鉴权、计费、额度拒绝、独立重置和再次鉴权。

探针：100 万输入 Token（其中 20 万缓存读、10 万缓存写）及 10 万输出 Token；基础输入 $2/M、输出 $10/M、缓存读 $0.5/M、缓存写 $3/M，倍率 1.1。实际扣费 $3.08，Token 明细保持真实。重置 7 天周期后恢复通过，30 天消费和历史保留；ABI 返回的嵌入页面包含 V5 功能。

临时本地服务已停止，浏览器验收任务已关闭。
