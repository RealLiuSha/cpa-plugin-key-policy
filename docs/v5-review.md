# V5 回归 review 与增强记录

日期：2026-09-12。基于已完成的 V5 实现继续审查并修正，范围为数据迁移、额度重置、计费倍率和管理页面交互。全部变更留在本地 `v5` 工作区；未改依赖、提交或部署。

## 发现并修复的问题

### P1：迁移恢复点未完整校验，回退再升级可能保留过旧备份

原实现复用备份时只检查外层数据集标识。即使备份里的 state 已损坏，也可能继续升级；如果管理员恢复旧版后继续产生消费，再次升级还可能沿用第一次的备份，遗漏两次升级之间的数据。

现在由迁移入口复用持久化读取的严格解析规则，检查备份内 state/usage 的格式、版本与配对标识。部分迁移恢复还要求未迁移的 state 与备份原文一致。回退后再次升级会先按内容摘要归档旧备份，再保存当前完整数据对，成功后才开始替换源文件。损坏或不匹配的备份会阻止迁移，源数据保持原样。

责任位置：`internal/policy/migration.go`、`internal/policy/persistence.go`。验证包括损坏备份的修复前复现、修复后拒绝、回退再升级保留两个恢复点，以及 usage 已写成 v5 而 state 仍为旧版的恢复。

### P2：过期重置预览可能再次清零或改变到期日

弹窗打开后，如果跨过零点，或者其他管理员已重置该周期，原确认仍可能清空新周期消费，或得到与预览不同的下次日期。

现在界面提交所见周期的开始时间和拟重置日期，账本在持有同一把锁时检查并执行重置。过期预览返回 `409 quota_changed`；弹窗重新读取数据，保留选中的周期，等待用户再次确认，不自动重试写入。旧 API 调用未提供 `expected` 时继续兼容。其他请求正常产生消费不会单独使预览失效；校验关注周期身份和日期变化。

责任位置：`internal/policy/quota.go`、`internal/policy/admin.go`、`internal/plugin/app.go`、`web/src/components/QuotaResetDialog.tsx`。固定时钟验证跨日、被再次重置、当前预览三种情况；浏览器通过真实本地插件接口验证冲突提示及再次确认。

### P2：编辑页操作不一致，嵌套导航丢失返回上下文

编辑页原先仍使用原生确认框，手机端更换 Key 的入口也不完整；从 Key 编辑进入新建模型再返回，列表筛选上下文未完整传递。

现在列表与编辑页复用 Key 操作弹窗，统一处理中途等待、失败重试、更换和删除确认。手机和桌面都能直接重置额度、更换 Key。操作成功与后续列表刷新失败分别反馈，避免把已经成功的操作误报为失败。Key 编辑草稿、嵌套模型导航和返回列表的筛选条件一起保留。

责任位置：`web/src/components/KeyActionDialog.tsx`、`web/src/components/KeyMoreMenu.tsx`、`web/src/pages/KeyEdit.tsx`、`web/src/components/KeyForm.tsx`、`web/src/pages/ModelForm.tsx`。手机端实际更换 Key 后，未保存名称仍在；进入新建模型再取消后草稿仍在，返回列表保留“张三”筛选。

### P3：倍率编辑和弹窗键盘操作存在阻碍

倍率直接存为数字时，清空输入会立即变成 0，不利于连续编辑；固定步长限制了更多小数位。免费开关在编辑过程中还会提前清掉价格。

倍率现在保留字符串草稿，保存时校验为不小于 1 的有限数字；使用 `step="any"`，支持 `1.125`。免费开关只切换编辑状态，提交免费模型时才归零价格。模型目标选择往返也保留倍率草稿。弹窗补齐初始焦点处的 Shift+Tab 循环，避免直接跳出弹窗。

责任位置：`web/src/pages/ModelForm.tsx`、`web/src/components/Modal.tsx`。浏览器逐键输入 `1.125` 并保存回读成功，输入/输出最终计费价为 $2.25 / $11.25；免费开关往返保留原价格。

## 与原预期的一致性

| 规则 | 本轮结论 |
| --- | --- |
| CPA 不二开，对外仍为通用认证拒绝 | 保持；插件仍实际执行额度限制，没有恢复无效的 Rejection 输出 |
| 每个 Key 独立的日、7 天、30 天周期 | 保持；只重置选中周期，日期按配置时区的自然日计算 |
| 重置不删历史，不清其他周期 | 保持；浏览器确认 7 天恢复后，30 天消费仍为 $3.30 |
| 倍率只作用于后续金额，实际 Token 不变 | 保持；免费及按次规则不变，导入基础价格保留倍率 |
| 旧数据迁移不赠额度、不重算历史 | 保持；真实 v4 副本再次演练通过 |
| 交互简洁，桌面和移动操作一致 | 增强确认、错误反馈、草稿和返回路径，未增加新的配置步骤 |
